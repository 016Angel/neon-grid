# Neon Grid

Mod para Claude Code con estética cyberpunk: negro, amarillo neón y cian, esquinas recortadas y franjas de advertencia.

- **Panel NEON // GRID** al lado del chat: estado actual (en espera o ejecutando), contadores de turnos y herramientas, duración del último turno y un registro de las herramientas que usa Claude.
- **Franja arriba del prompt**: `// CONEXIÓN ESTABLECIDA_`, la herramienta en curso y botones PANEL y OCULTAR.
- **Comando `/neon`**: vuelve a abrir el panel y la franja.

## Instalar

En una sesión de Claude Code, escribe:

```
/plugin install neon-grid --marketplace 016Angel/neon-grid
```

Responde `y` para agregar el marketplace y luego elige el alcance (scope) de la instalación.
